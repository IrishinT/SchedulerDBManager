# SchedulerDBManager

Приложение для планирования и управления рабочими сменами на производственных участках.

Разработчикам доступно описание внутренних интерфейсов и логики взаимодействия слоев в разделе: [Техническая спецификация API](API/Index.md).

---

## Системные требования

* **Операционная система:** Windows.
* **Платформа:** .NET Runtime 8.0.
* **СУБД:** Установленный драйвер Microsoft.ACE.OLEDB.12.0. 

---

## Структура решения

Проект разделен на изолированые решения:
1. **SchedulerDBManager.Presentation** — графический интерфейс пользователя (Windows Forms). Содержит формы отображения, редактирования данных, обработку прав доступа и экспорт отчетов.
2. **SchedulerDBManager.BusinessLogic** — слой бизнес-логики. Отвечает за валидацию входных параметров, автоматические расчеты и выполнение связанных каскадных операций.
3. **SchedulerDBManager.DataAccess** — слой доступа к данным. Реализует паттерн репозитория для выполнения параметризованных запросов к файлу базы данных `.accdb`.
4. **SchedulerDBManager.Tests** — библиотека модульных и интеграционных тестов на базе xUnit и Moq.

## Руководство пользователя

### 1. Подключение к базе данных
При запуске приложения открывается стартовое окно «Подключение к БД».
* Нажмите кнопку со значком папки, чтобы выбрать файл базы данных (`.accdb`) на диске, либо введите путь вручную.
* Нажмите «Подключиться». Программа выполнит проверку соединения и наличие необходимых драйверов. В случае успешной проверки откроется форма авторизации.

### 2. Авторизация и разграничение прав доступа
Для входа в систему введите учетные данные пользователя. Права доступа зависят от роли, назначенной учетной записи:

* **Читатель** (Роль 1):
  * Доступен просмотр всех таблиц (Смены, Участки, Подразделения).
  * Доступна фильтрация, поиск по записям и экспорт данных в CSV.
  * Кнопки создания, изменения и удаления скрыты или неактивны.
* **Редактор** (Роль 2):
  * Доступны все возможности Читателя.
  * Разрешено создание, изменение и удаление подразделений, участков и смен.
  * Закрыт доступ к списку пользователей.
* **Администратор** (Роль 3):
  * Полный доступ к управлению справочниками и расписанием.
  * Доступен раздел «Пользователи» для создания, редактирования и удаления учетных записей сотрудников.

### 3. Работа с интерфейсом таблиц
Основные разделы (Смены, Участки, Подразделения, Пользователи) наследуют общую структуру интерфейса:
* **Левая панель управления:** Содержит кнопки действий (Создать, Редактировать, Удалить), кнопку «Справка» с локальным руководством для конкретного раздела и кнопку «Экспорт в CSV».
* **Верхняя панель фильтрации:** Предоставляет инструменты для быстрого поиска по текстовым полям, фильтрации по связанным объектам и сортировки содержимого таблицы.
* **Основная таблица (DataGridView):** Отображает текущий список записей. Для выбора строки кликните по ней в любом месте.

### 4. Особенности ведения данных и каскадные операции

* **Подразделения:**
  * Содержат название отдела и ФИО руководителя.
  * При удалении подразделения через `DepartmentService` запускается каскадный процесс удаления: сначала удаляются все смены, привязанные к участкам этого подразделения, затем сами участки, и только после этого удаляется запись подразделения.
* **Участки:**
  * Закрепляются за определенным подразделением и содержат адрес и контактный телефон.
  * При изменении адреса участка связанные смены автоматически обновляют отображаемый адрес.
  * Удаление участка влечет за собой автоматическое удаление всех связанных с ним смен.
* **Смены (Расписание):**
  * При создании или редактировании смены указываются время начала и окончания работы, количество задействованных сотрудников, ФИО начальника и целевой участок.
  * **Автоматические вычисления:** Программа самостоятельно вычисляет длительность смены в часах (разница между временем окончания и начала) и определяет дату смены на основе времени начала.
  * Валидация не позволит сохранить смену, если время окончания меньше или равно времени начала, либо если количество рабочих выходит за установленные лимиты.

### 5. Экспорт данных
Для выгрузки текущего состояния таблицы в Excel или другие редакторы:
* Настройте нужные фильтры на панели поиска.
* Нажмите кнопку «Экспорт в CSV».
* Выберите путь для сохранения файла. Программа автоматически сформирует файл с кодировкой UTF-8 (включая BOM) и разделителем «точка с запятой» для корректного открытия русскоязычного текста в Microsoft Excel.
